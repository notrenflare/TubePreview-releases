# Security

If you find a security issue, please [report it privately](https://github.com/notrenflare/TubePreview-releases/security/advisories/new).
Include the app version, steps to reproduce it, and what could be affected.
Please keep personal information and credentials out of public issues.

## Release checks

Each release includes a SHA-256 checksum and the signing certificate fingerprint
so you can check the file you downloaded. These are available with the
[latest release](https://github.com/notrenflare/TubePreview-releases/releases/latest).

The published TubePreview 1.0 APK was scanned on October 9, 2026, with
**0 detections from 67 vendors**. Eight additional vendors could not process the
file type. [View the VirusTotal report](https://www.virustotal.com/gui/file/b5c61ac33e3c787073b254a658a927343db7f9f4dccc7b6593fc9afbd5ca3304/detection).

The report is for APK SHA-256:

```text
b5c61ac33e3c787073b254a658a927343db7f9f4dccc7b6593fc9afbd5ca3304
```

## Installation help

If Google Play Protect displays a message during installation, check its details
and [Google's guidance](https://developers.google.com/android/play-protect/warning-dev-guidance).
A Play Protect appeal has been submitted for this release.
