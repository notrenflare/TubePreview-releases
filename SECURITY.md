# Security

Please report potential vulnerabilities privately through
[GitHub's vulnerability reporting form](https://github.com/notrenflare/TubePreview-releases/security/advisories/new).

Include the affected app version, reproduction steps, and potential impact.
Remove personal information from logs and screenshots. Do not publish passwords,
API keys, signing keys, or sensitive reports in public issues.

Security fixes are distributed in the latest signed APK release. Install updates
over the existing app to retain your local preview data.
